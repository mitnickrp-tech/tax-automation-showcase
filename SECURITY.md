# Security and Responsible Disclosure

This repository is a public documentation showcase. It is not the production application and must not be used to submit customer data, tax documents, credentials, or confidential business information.

## Scope

The public repository intentionally excludes:
- Production source code and proprietary tax rules.
- API keys, passwords, tokens, private certificates, and environment files.
- Customer records, fiscal documents, and personally identifiable information.
- Private integration endpoints and customer-specific configuration.

## Reporting a concern

If you identify a possible disclosure in this public showcase, please do not publish sensitive details in a public issue. Contact the repository owner privately through their GitHub profile.

## Important

A public README or architecture diagram is not evidence of a security audit, certification, or regulatory approval. Production deployments require their own security review, access controls, monitoring, backup strategy, and operational procedures.
